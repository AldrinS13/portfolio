HC Time Log Audit Tool

A reconciliation tool that checks every health coach's time log entry against the official care-platform record, so QA no longer compares them by hand.

Role
Data, Reporting & Admin Analyst
Built in
Google Sheets, no add-ons
Scale
About 50 coaches, tens of thousands of rows
Status
In use by QA; Date Validator in progress

At a glance

The problem

Coaches log time twice: in the care platform (TC), the official system, and in a personal Time Log tracker. QA checked the two entry by entry. It was slow, and mismatches were easy to miss.

The solution

Paste each day's exports into the sheet. The tool pairs every entry across both systems and flags what is missing, mistimed or inconsistent. Filters narrow it by coach, clinic or status.

The outcome

A full day of about 340 entries is reconciled in one view. Early tests matched over 97% of entries automatically, leaving QA only the exceptions.

How it works

  1. Paste

    Each day's TC export and Time Log export go into two raw tabs, one day at a time.

  2. Normalize

    Coach usernames, clinic spellings and three different time formats are converted to one clean form.

  3. Match

    Each Time Log entry looks for its TC twin using a four-part key, then gets a status.

  4. Report

    One formula builds the filterable table, KPI totals and per-coach and per-clinic checks.

What I built

Matching engine

  • Regex cleanup so TC usernames and Time Log emails resolve to the same coach
  • Minutes converter for three text formats
  • Visit counter that separates same-day repeat visits from visits on other days
  • Clinic Map and HC Roster tabs that standardize names
  • Three-tier time check: within 1 minute, within 3, beyond 3

Report and views

  • Single filterable table with coach, clinic and status dropdowns
  • Day at a Glance summary
  • Entries by Clinic comparison, TC against Time Log
  • Selected Coach Check: entry counts and total minutes side by side
  • Side-by-side TC and Time Log columns for tracing a flag

Safeguards

  • System Check light that warns when pasted data outruns the formulas
  • Date-first filtering so the sheet stays fast on large ranges
  • Known-answer test at every phase before moving on
  • Date Validator for mismatched or impossible dates (in progress)

Problems I traced and fixed

Each one was diagnosed from what the sheet actually showed, then fixed on a single cell before copying down.

Design decisions

One formula builds the report

Every column comes from the same filter, so rows can never drift out of line and the sheet stays fast. The trade-off is that new fields are added upstream, in the matching tab.

Task Type left out of matching

About 99% of TC entries carry the same category, so comparing it adds noise and no signal. This was a deliberate cut.

Built live in Sheets, not converted

A first Excel build broke when converted. Writing the formulas directly in Google Sheets removed that risk.

How it was built

I set the business rules, built the tool in phases and tested each phase against known-correct numbers before moving on. I used an AI assistant to draft formulas and step-by-step guides, and diagnosed each bug from what the sheet showed. Still open: testing across more days and finishing the Date Validator.
